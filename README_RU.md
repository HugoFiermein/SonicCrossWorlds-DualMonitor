# CrossWorldsFix — Патч для игры на 2 мониторах (2 Игрока)

[**English**](README.md) | [**Русский**](README_RU.md)

**CrossWorldsFix** — модификация (ASI-плагин) для игры **Sonic Racing: CrossWorlds** (Unreal Engine 5.4), созданная специально для полноценного **кооператива на двух физических мониторах** при игре вдвоём с 2 геймпадов через технологию **AMD Eyefinity** или **NVIDIA Surround** (соотношение 32:9, например 3840x1080 или 5120x1440).

Вместо того чтобы делить один монитор пополам с маленькими окнами, каждый игрок получает **свой собственный полноценный физический монитор** со своей камерой, изолированным HUD и интерфейсом!

---

## Основные возможности

### 🎮 Персональный экран для каждого игрока
- **Игрок 1 (Левый монитор)**: Полный обзор гонки и собственный HUD Игрока 1 на левом мониторе (0% — 50% виртуального рабочего стола 32:9).
- **Игрок 2 (Правый монитор)**: Полный обзор гонки и собственный HUD Игрока 2 на правом мониторе (50% — 100% виртуального рабочего стола 32:9).
- **Скрытие центральной полосы**: Отключает стандартную черную вертикальную разделительную полосу игры, чтобы она не накладывалась на рамки мониторов.

### 📋 Адаптация и разнесение меню по 2 мониторам
- **Меню выбора 2P (`WBP_Ready_M2`)**: Окна выбора персонажей, характеристик болидов и гаджетов для Игрока 1 центрированы строго на 1-м мониторе, а для Игрока 2 — строго на 2-м мониторе. Меню больше не разрезается рамкой мониторов по центру!
- **Меню паузы (`WBP_PauseMenu_C`)**: Параметры каждого игрока отображаются на его мониторе, а кнопки управления меню паузы центрируются на экране того игрока, кто вызвал паузу.
- **Общие меню**: Экраны выбора класса и трасс (`ClassSelect`, `CourseSelect`) аккуратно выровнены по первому монитору и не делятся стыком экранов пополам.

### 🎯 Исправление прицела при атаке вперед
- Устранен критический баг, из-за которого в режиме сплит-скрина при выборе предмета атаки вперед рисовалась только правая половина прицела (из-за некорректного сдвига координат вьюпорта). Теперь прицел отображается полностью и целится точно по центру машины.

## Быстрая установка

Установка предельно простая и состоит из **1 действия**:

1. Скачайте свежий архив релиза: [**`CrossWorldsFix-DualMonitor-v0.0.3.zip`**](https://github.com/HugoFiermein/CrossWorldsFix/releases/latest).
2. Распакуйте 3 файла из архива прямо в папку с игрой, где лежит исполняемый файл:
   ```
   SonicRacingCrossWorlds\UNION\Binaries\Win64\
   ```
   Файлы в архиве:
   - `CrossWorldsFix.asi`
   - `CrossWorldsFix.ini`
   - `winmm.dll` (Ultimate ASI Loader x64)

3. Включите **AMD Eyefinity** (или NVIDIA Surround) в драйвере вашей видеокарты, объединив два монитора в один рабочий стол 32:9 (например, 3840x1080).
4. Запустите игру в Steam, выберите разрешение 32:9 в полноэкранном режиме и наслаждайтесь игрой на двух отдельных мониторах!

### Steam Deck / Linux (Proton)
Если игра запускается через Wine/Proton:
- Откройте свойства игры в Steam -> **Параметры запуска** -> добавьте:
  ```bash
  WINEDLLOVERRIDES="winmm=n,b" %command%
  ```

---

## Удаление

Чтобы полностью удалить патч, достаточно просто стереть эти 3 файла из папки `SonicRacingCrossWorlds\UNION\Binaries\Win64\`:
- `CrossWorldsFix.asi`
- `CrossWorldsFix.ini`
- `winmm.dll`

Файлы игры остаются на 100% чистыми и нетронутыми.

---

## Настройка

Параметры можно настроить в конфигурационном файле [**`CrossWorldsFix.ini`**](CrossWorldsFix.ini):

```ini
[Dual Monitor Splitscreen]
Enabled = true               ; Включает режим вывода двух игроков на 2 монитора
HideCenterDividerLine = true ; Скрывает черную разделительную полосу игры по центру
Mirror2PMenus = true         ; Разносит элементы меню 2P по отдельным экранам игроков

[Fix Aspect Ratio]
Enabled = true               ; Активирует поддержку разрешения 32:9 без черных полос

[Fix HUD]
Enabled = true               ; Исправляет масштаб интерфейса и 3D-маркеры на трассе
```
